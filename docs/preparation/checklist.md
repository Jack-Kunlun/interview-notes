# 面试前检查清单

## 技术复习 ✅

### 核心知识点（必须完成）

- [ ] Vue（2 & 3）：响应式原理 / Composition API / 生命周期 / Diff 算法
- [ ] React：Hooks / Fiber / React 18 新特性 / 闭包陷阱
- [ ] TypeScript：泛型 / 工具类型 / `infer` / 类型守卫
- [ ] **CSS 深入**：BFC / 层叠上下文 / CSS 动画性能 / `clamp()`
- [ ] **浏览器原理**：渲染流程 / Event Loop / 缓存策略 / V8 GC
- [ ] **Node.js**：Event Loop 六阶段 / nextTick vs setImmediate / Stream / JWT

### 工程化与跨端

- [ ] Vite vs Webpack 原理对比
- [ ] uni-app 生命周期 / 分包策略
- [ ] Monorepo（pnpm workspace）

### 面试题过一遍

- [ ] A 组技术基础 10 题
- [ ] B 组实践应用 5 题
- [ ] C 组情景分析 3 题

---

## 项目材料 📁

- [ ] 简历打印 3 份（或确认电子版最新）
- [ ] 个人博客 / GitHub 项目确认可访问
- [ ] 作品集 / 核心项目截图准备好（如果有）
- [ ] 准备好 1-3 个最有深度的项目故事（用 STAR 格式背熟）

---

## 后勤准备 🗺️

- [ ] 面试地址确认（大楼 / 几层 / 门禁要求）
- [ ] 提前导航，确认所需时间，预留 20 分钟余量
- [ ] 确认面试形式（线上 / 线下）及视频软件（钉钉 / 飞书 / Zoom）
- [ ] 线上面试：摄像头 / 麦克风 / 网络测试；选安静、背景整洁的地方
- [ ] 面试当天着装（整洁商务休闲，技术岗相对宽松）

---

## 心态准备 🧠

- [ ] 睡眠充足（提前一天不要做高强度复习，避免疲劳）
- [ ] 提前熟悉自我介绍，脱稿练习 2-3 遍
- [ ] 遇到不会的题：承认不确定，说思路，不要瞎编
- [ ] 带纸笔，记录面试官的问题（显示专注，方便后续回顾）
- [ ] 面试后立即记录题目（趁热打铁，用于后续优化准备）
