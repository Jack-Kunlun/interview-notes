## [1.0.0] - 2026-08-11

### Added

- Initial public release
- Structured frontend knowledge base covering 23 technical directions
  - JavaScript, TypeScript, CSS, Algorithms
  - Vue (2 & 3), React, Data Visualization, SSR
  - Cross-platform: uni-app, Taro, React Native
  - Engineering: Build tools, Performance, Debugging, DevOps
  - Browser internals, Networking, Node.js, Architecture & permissions
- Interview question collections (practice + behavioral)
- Interview preparation resources (self-introduction, checklist, follow-up)
- VitePress-powered documentation site with full-text search
- Responsive documentation UI with custom ink theme
- Automated GitHub Pages deployment via GitHub Actions
- Theme quality audit with unit tests
- Open contribution workflow with Issue templates and PR template
